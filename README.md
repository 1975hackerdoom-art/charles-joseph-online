# Charles Joseph Online

Personal website for Charles Joseph covering faith, leadership, enterprise, books, property resources, mentorship and contact enquiries.

## Development

```text
npm.cmd install
npm.cmd run dev
```

The site includes six Insights articles, a property-guide download, and server-backed forms at `/api/forms`. Form delivery requires the SMTP variables described in `docs/charles-forms.md`.

## Main routes

- `/`
- `/about`
- `/insights`
- `/insights/[slug]`
- `/resources`
- `/mentorship`
- `/property-guide`
- `/contact`
- `/privacy`
